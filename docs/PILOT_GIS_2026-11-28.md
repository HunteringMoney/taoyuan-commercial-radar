## 產出

- `scripts/pilot_georeference.py`：至少 4 個**獨立核對**的影像控制點，最小平方法仿射校正、逐點留一誤差檢查，再轉紅色像素為草稿 GeoJSON。沒有控制點或誤差超標會停止，輸出一律標 `verified_zoning_geometry=false`。
- `config/pilot_control_points.json`：由官方第 2 層的七個可辨識紅色街廓角點，逐一對應截圖像素；分布在北、西、南、東，記錄 WGS84 座標與圖層 URL。先用官方圖形與截圖紅色遮罩自動對齊作為挑點輔助，然後目視確認角點。七點留一預測誤差 0.61–2.00 公尺；這是**同一圖層內部配準誤差**，不是獨立測量精度，也尚未證明法定圖面最新版本。
- `docs/pilot_red_draft.geojson`：實圖 106 個紅色草稿多邊形，全部標 `verified_zoning_geometry=false`，可用於試驗搜尋。對照官方第 2 層，草稿紅區約 537,448 平方公尺，其中 503,416 平方公尺（93.67%）與當下商業區圖形重疊；約 8 平方公尺與住宅區圖形重疊，屬邊界套合誤差，**不可單獨用截圖草稿判定分區**。上述面積僅為 GIS 診斷近似值，不是地籍面積。
- `scripts/pilot_scout.py`：同時要求整個 OSM 建物輪廓位於官方商業區圖形內、並與已配準截圖紅區重疊至少 95%，再分群。住宅區、其他分區和跨界輪廓均排除。當場產出 **1 個實際座標的待查建物群**，位於 `(121.3126472, 24.9961143)`，包含 5 個 OSM 建物輪廓；見 `docs/pilot_scout_candidates.json`。它不是 5 筆地號，也不是已確認開發基地。
- 正式 `docs/targets.json` 維持空名單。法定計畫版本、圖層授權、候選地籍與實勘未查核完成，不能把待查線索升級成正式目標。

## 重現方式

安裝 `shapely>=2,<3`、`numpy>=2,<3`、`opencv-python-headless>=4.10,<5`。原始截圖已存 `docs/assets/pilot_zoning_screenshot.png`；檔案 SHA-256 必須與控制點檔相同。已有七個控制點，可重新檢查或更正後執行：

```bash
python scripts/pilot_georeference.py --image docs/assets/pilot_zoning_screenshot.png --control-points config/pilot_control_points.json --output input/pilot_red_draft.geojson --report input/georeference_report.json
```

使用官方第 1、2 層的小範圍 `f=geojson` 查詢結果和 OSM Overpass `way["building"]` `out geom` 匯出為本機輸入。來源、時間、範圍、授權與原始回應雜湊應保留在本機；不可在 public 儲存庫放入未授權原始圖資或個資。再執行：

```bash
python scripts/pilot_scout.py --zoning input/official_commercial_raw.geojson --parcel input/anchor_parcel_raw.geojson --osm input/osm_buildings_raw.json --red-scope input/pilot_red_draft.geojson --scope-output input/pilot_official_reference.geojson --output input/pilot_scout_candidates.json
```

`pilot_official_reference.geojson` 是**本機診斷參考層**，不應與截圖草稿 GeoJSON 或法定分區公告向量混同。正式發布仍須核對官方計畫版本、截圖控制點、候選建物及地籍；住宅區一律不得納入。

## 驗證結果與卡點

- 本機 10 項幾何、校正及雙重分區遮罩單元測試通過；舊 Actions run `46121900529` 的候選測試失敗，原因是 `shapely.ops.transform` 對座標 tuple 做 Python 重複運算造成 GEOS 記憶體錯誤；改用 `shapely.affinity.scale` 後舊 5 項測試本機通過。
- 七個控制點已產出實圖草稿 GeoJSON，留一誤差最高 2.00 公尺；因為控制點都取自同一官方圖層，還需另一套獨立圖資或人工現地查核評估絕對定位誤差。草稿可測試，但未完成法定分區認證。
- 市府 MapServer 當下可讀，不代表可任意批量重製、公開其全部向量；此處只以小範圍查詢作診斷。最新公告版本及使用授權仍待查。
- OSM 小範圍只有 82 個 way，能形成 1 群；不能推稱已有 10 處基地或全區涵蓋完成。
